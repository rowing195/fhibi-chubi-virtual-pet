修正版，適用獨立桌寵版本。

- 主畫面點「把小事放在桌面上」時，畫面不再先往下跳一下才切換；其他換頁也一樣。
- 桌面 widget 的待辦改成一張張小卡片，最底下露出被切掉的卡片、捲動時上下淡出，看得出還有更多；標題旁顯示總件數，「清除已完成」改成標題列的圖示，只在有已完成項目時出現。
- widget 又可以縮到一格高（0.2.0 時被限制成至少 180dp）。
- 維持純本機功能，不含相機、網路、AI 或 AirScroll 整合。

驗證：release 編譯與 Lint 通過；模擬器上 8 項 Android instrumentation 通過，其中新測試確認切換時主畫面不再位移（修正前位移 168px）。
